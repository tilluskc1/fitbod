# Credits

Every file and folder in `public/`, where it came from and under what licence. An entry that cannot
be proven from the repository, its git history or the file itself says **not recorded** or **not found**.
Nothing here is guessed to look complete. `tests/credits254.test.ts` fails when something in `public/` has
no entry below, or an entry names a path that no longer exists.

Short version in the app: Settings > About > Credits (#253).
