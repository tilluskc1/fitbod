# 03: The target sheet stops claiming derivation we don't do

**What to build:** The "Why this target" sheet describes the target truthfully. When a previous
session exists it explains the target as derived from those sets. When none exists it describes the
target as what the program prescribes, instead of saying it came from a session that never happened.

**Blocked by:** 01 (a fresh account must first stop showing a fabricated last session, or the
sentence has nothing honest to say)

**Status:** ready-for-agent

- [ ] With no history, the sheet says the target is prescribed by the program and shows no
      last-session values
- [ ] With history, the sheet still shows last completed sets, working load and today's target, and
      its explanation matches how the target was actually produced
- [ ] The explanatory prose about rep ranges and load steps is kept as written
- [ ] No prescription, stored value or export field changes
